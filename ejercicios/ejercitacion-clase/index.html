    Ejercitación para Resolver en Clases

    Ejercicios para practicar durante las clases. Resuelve cada uno aplicando el Teorema Fundamental y los métodos aprendidos.

    Ejercicio 1: Conversión Hexadecimal Básica

    Enunciado: Convertir \((A5F)_{16}\) a decimal.

    Pista: Recuerda que A=10, F=15

    Debes obtener como resultado \((2655)_{10}\)

    Ejercicio 2: Identificación de Base

    Enunciado: Un número en base desconocida es \((223)_B\) y su equivalente en decimal es \((35)_{10}\).

    ¿Cuál es la base B?

    Pista: Plantea la ecuación usando Teorema Fundamental: $\(2 \cdot B^2 + 2 \cdot B + 3 = 35\)$

    Debes obtener \(B = 3\)

    Ejercicio 3: Conversión Binaria con Fracciones

    Enunciado: Convertir \((1010.0101)_2\) a decimal.

    Pista: Separa parte entera y fraccionaria: - Parte entera: usa exponentes positivos - Parte fraccionaria: usa exponentes negativos

    Debes obtener \((10.3125)_{10}\)

    Ejercicio 4: Pasaje Rápido Binario a Octal

    Enunciado: Sin convertir a decimal, cambiar \((11010101)_2\) a octal usando agrupación de 3 bits.

    Pista: Agrupa de derecha a izquierda en grupos de 3 bits: \((011)(010)(101)_2\)

    Debes obtener \((325)_8\)

    Ejercicio 5: División Sucesiva (Decimal a Hexadecimal)

    Enunciado: Convertir \((255)_{10}\) a hexadecimal usando división sucesiva.

    Pista: Recuerda que los restos se convierten a símbolos hexadecimales (0-9, A-F)

    Debes obtener \((FF)_{16}\)

    Ejercicio 6: Comparación de Bases

    Enunciado: ¿Cuál de estos números es mayor?

    • \((1111)_2\)
    • \((17)_8\)
    • \((10)_{16}\)
    • \((15)_{10}\)

    Pista: Convierte todos a decimal y compara.

    Debes encontrar que \((17)_8 = 15_{10}\) es el mayor, empatando con \((15)_{10}\)

    Ejercicio 7: Combinada de Conversiones

    Enunciado:

    a) Convertir \((1001)_2\) a decimal b) Convertir el resultado a hexadecimal c) Convertir \((9)_{10}\) a octal

    Pista: - Usa Teorema Fundamental en (a) - Para (b), recuerda que \((9)_{10} = (1001)_2 = (9)_{16}\) - Para (c), usa división sucesiva por 8

    Debes obtener: - a) \((9)_{10}\) - b) \((9)_{16}\) - c) \((11)_8\)

    Autoevaluación

    ✓ ¿Puedo aplicar correctamente el Teorema Fundamental?

    ✓ ¿Comprendo cómo funcionan los exponentes negativos para fracciones?

    ✓ ¿Puedo hacer divisiones sucesivas sin errores?

    ✓ ¿Puedo hacer agrupaciones rápidas entre Binario, Octal y Hexadecimal?

    ✓ ¿Puedo identificar una base desconocida resolviendo ecuaciones?
