    Ejercicios y Prácticas

    Colección completa de ejercicios para practicar los conceptos de Organización de Computadoras I.

    Niveles de Dificultad

    1. Ejercicios Resueltos — Nivel: Básico

    5 ejercicios paso a paso con soluciones completas. Comienza aquí si eres nuevo en el tema.

    Contenido: - Conversión Binario → Decimal - Conversión Hexadecimal → Decimal - Conversión Octal → Decimal - Conversión con Parte Fraccionaria - Identificar Base Desconocida

    Objetivo: Entender la metodología y ver ejemplos resueltos.

    2. Práctica para Parcial — Nivel: Intermedio

    5 ejercicios de nivel examen con dificultad creciente.

    Contenido: - Conversiones múltiples con fracciones - Ecuaciones para encontrar bases - Pasajes rápidos sin convertir a decimal - División sucesiva - Fracciones binarias

    Objetivo: Prepararse para la evaluación parcial.

    3. Ejercitación en Clase — Nivel: Avanzado

    7 ejercicios para resolver en clase con pistas pero sin soluciones completas.

    Contenido: - Conversión Hexadecimal básica - Identificación de bases - Binarias con fracciones - Pasajes rápidos - División sucesiva en bases diversas - Comparación de números en diferentes bases - Ejercicios combinados

    Objetivo: Práctica activa durante la clase.

    Estrategia de Estudio Recomendada

    Semana 1: Fundamentos

    1. Lee Estructura Numérica y Potenciación
    2. Resuelve Ejercicios Resueltos — estudia cada paso

    Semana 2: Teoría Aplicada

    1. Lee Sistemas Numéricos y Teorema Fundamental
    2. Resuelve Ejercicios Resueltos nuevamente sin mirar soluciones
    3. Intenta 2-3 ejercicios de Práctica para Parcial

    Semana 3: Métodos Específicos

    1. Lee Métodos de Conversión
    2. Resuelve Ejercitación en Clase — 2-3 ejercicios diarios
    3. Resuelve Práctica para Parcial completamente

    Semana 4: Repaso e Integración

    1. Resuelve todos los ejercicios nuevamente sin mirar soluciones
    2. Usa Tablas Rápidas como referencia
    3. Consulta Tabla de Equivalencias para verificar

    Checklist de Competencias

    Después de completar todos los ejercicios, deberías poder:

    • ✓ Aplicar el Teorema Fundamental correctamente a cualquier base
    • ✓ Realizar conversiones de Decimal a cualquier base usando división/multiplicación sucesiva
    • ✓ Hacer conversiones rápidas entre Binario-Octal-Hexadecimal
    • ✓ Resolver ecuaciones para encontrar bases desconocidas
    • ✓ Trabajar con partes fraccionarias en conversiones
    • ✓ Verificar resultados usando el Teorema Fundamental
    • ✓ Identificar y corregir errores en conversiones
    • ✓ Resolver ejercicios bajo presión (examen)

    Tips para Resolver Ejercicios

    1. Siempre indica la base: \((26)_{10} = (11010)_2\)
    2. Verifica tus resultados: Usa Teorema Fundamental para comprobar
    3. Mantén organización: Escribe paso a paso para evitar errores
    4. Usa tablas rápidas: No necesitas calcular \(2^{10}\) cada vez
    5. Practica el cálculo mental: Memoriza potencias de 2 hasta \(2^{10}\)
    6. Identifica patrones: Binario-Octal (3 bits), Binario-Hexadecimal (4 bits)
