## 📌 Puntos Clave

### **Conceptos Fundamentales**
- **Punto Fijo (C2)**: Usa complemento a 2 para negativos
- **Punto Flotante**: Solo bit de signo, NO se complementa
- **Factor de Escala**: 2^n (SOLO depende de bits fraccionarios)
- **Overflow**: Ocurre cuando operandos del mismo signo dan resultado de signo opuesto

### **En el Examen**
✅ Se permite usar calculadora científica (verificar modo)  
✅ Se permite usar referencias impresas  
❌ No se permiten teléfonos celulares  
❌ No se permiten trabajos prácticos (TP)  

### **Materiales por Tener a Mano**
- Plantillas de suma y resta (impresas)
- Tabla de verdad de suma binaria
